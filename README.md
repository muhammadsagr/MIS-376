# تحويل الهيكل الوظيفي من PowerPoint إلى Excel
**OrgChart PPTX → XLSX Converter**

برنامج بايثون كامل يقرأ الهيكل الوظيفي (Organizational Chart) من ملف عرض تقديمي
`.pptx` ويحوّله إلى ملف Excel منسّق يحتوي على الأسماء والمسميات الوظيفية والأقسام
والمدير المباشر والمستوى الإداري لكل وظيفة.

---

## 1. ما الذي يستطيع البرنامج قراءته؟

| نوع المخطط في PowerPoint | كيف يُقرأ |
|---|---|
| **SmartArt** (إدراج ← SmartArt ← تسلسل هرمي) | يُقرأ التسلسل من بيانات المخطط نفسها، فتكون النتيجة مطابقة تمامًا للأصل |
| **مربعات + خطوط ربط (Connectors)** | يُقرأ الارتباط بين كل مربع والمربع المرتبط به، والمربع الأعلى يُعتبر المدير |
| **مربعات بدون خطوط ربط** | يُستنتج التسلسل من مواقع المربعات على الشريحة (صفوف من الأعلى للأسفل) |
| **جدول داخل الشريحة** | يُقرأ من الأعمدة: الاسم / المسمى الوظيفي / القسم / المدير المباشر |
| **مجموعات (Groups)** | يدخل داخل المجموعات ويعالج الأشكال بداخلها |

---

## 2. ملف Excel الناتج

يحتوي على ثلاث أوراق:

1. **الهيكل الوظيفي** — جدول كامل بأعمدة: م، الشريحة، عنوان الشريحة، المستوى،
   الاسم، المسمى الوظيفي، القسم، المدير المباشر، عدد المرؤوسين المباشرين،
   إجمالي المرؤوسين، المسار الوظيفي، المصدر، المعرّف، النص الأصلي.
   (مع تجميد الصف الأول، وفلترة تلقائية، وتلوين حسب المستوى الإداري)
2. **العرض الشجري** — عرض متدرّج بالإزاحة يوضح شكل الشجرة.
3. **ملخص وتقرير** — إحصائيات (عدد الوظائف، عدد المستويات، توزيع الأقسام)
   بالإضافة إلى أي تنبيهات ظهرت أثناء التحويل.

## 3. التشغيل باستخدام Visual Studio

### أ) Visual Studio 2022 (النسخة الكاملة)

1. من **Visual Studio Installer** تأكد من تثبيت حِمل العمل
   **Python development** (تطوير بايثون).
2. افتح الملف `OrgChartConverter.sln` من داخل Visual Studio
   (File ← Open ← Project/Solution).
3. في **Solution Explorer** انقر بزر الفأرة الأيمن على **Python Environments**
   ← *Add Environment…* ← اختر بيئة Python 3.9 أو أحدث.
4. انقر بزر الفأرة الأيمن على المشروع ← *Python* ← *Install from requirements.txt*
   (أو نفّذ في الطرفية: `pip install -r requirements.txt`).
5. اضغط **F5** لتشغيل البرنامج، وستظهر الواجهة الرسومية.
   - لتشغيل تحويل مباشر بدون واجهة: انقر بزر الفأرة الأيمن على المشروع ←
     *Properties* ← *Debug* ← ضع في **Script Arguments** مثلًا:
     `samples/sample_orgchart.pptx -o result.xlsx --tree`

### ب) Visual Studio Code

1. ثبّت إضافة **Python** من Microsoft.
2. افتح مجلد المشروع (File ← Open Folder).
3. من الطرفية (Terminal ← New Terminal):
   ```bash
   python -m venv env
   env\Scripts\activate        # على ويندوز
   pip install -r requirements.txt
   ```
4. اضغط **F5** واختر أحد إعدادَي التشغيل الجاهزين في `.vscode/launch.json`.

### ج) بدون أي محرر (سطر الأوامر)

```bash
pip install -r requirements.txt
python main.py                                  # فتح الواجهة الرسومية
python main.py chart.pptx                       # تحويل مباشر
python main.py chart.pptx -o result.xlsx --tree # مع طباعة الشجرة
```

على ويندوز يمكن أيضًا النقر المزدوج على الملف `run_gui.bat`.

## 4. خيارات سطر الأوامر

| الخيار | الوظيفة |
|---|---|
| `input` | مسار ملف `.pptx` (إذا لم يُذكر تُفتح الواجهة الرسومية) |
| `-o, --output` | مسار ملف الإكسل الناتج (الافتراضي: نفس اسم العرض + `_OrgChart.xlsx`) |
| `-s, --slides` | تحديد الشرائح، مثال: `1,3,5-7` |
| `--include-titles` | إدراج عناوين الشرائح كعناصر ضمن الهيكل |
| `--no-tables` | تجاهل الجداول الموجودة في الشرائح |
| `--no-smart-text` | إيقاف الفصل الذكي بين الاسم والمسمى الوظيفي |
| `--no-geometry` | إيقاف استنتاج التسلسل من مواقع المربعات |
| `--ltr` | إخراج ورقة إكسل باتجاه من اليسار لليمين |
| `--tree` | طباعة الهيكل على الشاشة بعد التحويل |
| `-q, --quiet` | إخفاء الرسائل |
| `--gui` | فتح الواجهة الرسومية |

## 5. الاستخدام كمكتبة داخل كود آخر

```python
from orgchart import convert

excel_path, nodes, result = convert("company.pptx", "company.xlsx", slides=[1, 2])

for node in nodes:
    print("  " * (node.level - 1), node.name, "-", node.title)

print("عدد التنبيهات:", len(result.warnings))
```

## 6. هيكل المشروع

```
main.py                    نقطة التشغيل
orgchart/
    models.py              نماذج البيانات (OrgNode / ExtractionResult)
    textparse.py           فصل الاسم والمسمى والقسم من نص المربع
    extractor.py           قراءة الأشكال و SmartArt والجداول وخطوط الربط
    hierarchy.py           بناء الشجرة وحساب المستويات وعدد المرؤوسين
    exporter.py            كتابة ملف الإكسل وتنسيقه
    converter.py           الدالة الجامعة convert()
    cli.py                 واجهة سطر الأوامر
    gui.py                 الواجهة الرسومية (Tkinter)
samples/make_sample.py     إنشاء ملف PowerPoint تجريبي للاختبار
tests/test_converter.py    اختبارات وحدة (12 اختبارًا)
```

---

## 9. ملاحظات مهمة

- الصيغة المدعومة هي `.pptx` / `.pptm` فقط. إذا كان ملفك بصيغة `.ppt` القديمة
  فافتحه في PowerPoint واحفظه باسم بصيغة `.pptx`.
- إذا كانت المربعات غير مرتبطة بخطوط ربط حقيقية، يعتمد البرنامج على المواقع،
  لذا راجع عمود «المدير المباشر» في الناتج للتأكد.
- إذا احتوى المربع على سطر واحد فقط، يُعتبر اسمًا إلا إذا كان يحوي كلمة وظيفية
  (مدير، رئيس، Manager، Director…) فيوضع في عمود المسمى الوظيفي.
